# MedVault App Design

Static design board for the MedVault app: one app for every member, five tabs (Vault, Results, Insurance, Health, More) per the developer brief of 12 Oct 2026, with Coming soon states for features not yet available and a phase and dependency roadmap.

- `index.html` is the board.
- `images/` holds the logos it uses and a full-page PNG export of the v1 board.

Deploy on Vercel as a static site: no build command, output directory is the repo root.
